## 🚀 version: 0.1.0 📅 10/11/2026

### 🎯 Summary

Initial public release of **Penoos** — a progressive microservices framework for Rust, inspired by the architecture of PenoosJS and most compatible with it.

This version establishes the foundational project structure, licensing, documentation, and core vision for a high-performance, type-safe microservices framework written in pure Rust.

### 📌 Notes

- Penoos is an **independent** project and is **not** an official port of Penoos.
- The architecture and design are heavily inspired by PenoosJS, but the implementation is a clean-room rewrite in Rust.
- Protocol-level compatibility with Penoos is planned for future versions (optional).
- The project is currently in early development. Expect rapid iteration and possible breaking changes in the `0.x` series.
