# AI Agent Instructions

This file is an entry point for AI coding agents. The canonical rules live in `docs/`.

Before you change code, read in this order:

1. [docs/agents/rules.md](docs/agents/rules.md): master rules, definition of done, forbidden patterns.
2. [docs/agents/README.md](docs/agents/README.md): personas and skills index.
3. [docs/architecture/overview.md](docs/architecture/overview.md): system architecture and known gaps.

Skills live in `docs/agents/skills/`. Personas live in `docs/agents/personas/`.
Both are exposed to tools through symlinks in `.agents/`, `.claude/`, and `.github/`.
